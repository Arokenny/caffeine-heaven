# Caffeine Heaven - Coffee Shop Landing Page

A responsive landing page built with HTML, CSS, and a little JavaScript.

**Design reference:** [Caffeine Heaven - Coffee Shop Landing Page by Rijal (Dribbble)](https://dribbble.com/shots/24400687-Caffeine-Heaven-Coffee-Shop-Landing-Page)

## Sections
1. Hero
2. Gallery
3. Menus
4. Location
5. Testimonial
6. Membership

## Files
- `index.html` - page structure
- `style.css` - colors, layout, and responsive rules
- `script.js` - contact form message

## Run
Open `index.html` in a browser. An internet connection is needed for the fonts and images.
